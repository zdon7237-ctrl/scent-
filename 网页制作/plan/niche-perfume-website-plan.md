# 小众香水买手店网站设计想法与制作计划

## 1. 项目定位

我们的网站应定位为一个“内容型小众香水电商”，而不是单纯的商品陈列页。

核心目标是：

- 建立买手店的审美与专业感
- 让用户相信我们懂香水、会选品、能提供好的选香体验
- 让用户能快速找到适合自己的香水
- 支持新品上架、品牌故事、香水文章、试香服务和线上购买

参考方向：

- Scented Niche：更像精品买手店，重点在品牌故事、新品故事、调香师背景、门店体验和顾客评价
- Taigrance：更像完整电商目录，重点在品牌列表、商品详情、购物车、收藏、香调、规格和配送信息

我们的方向可以结合两者：用 Scented Niche 的编辑感和故事感，加上 Taigrance 的完整购买链路。

## 2. 网站整体结构

建议网站主导航包括：

- 首页
- 新品 New In

- 首页

- 关于我们

## 3. 首页设计

首页的任务不是把所有商品都展示出来，而是快速传达“这是一家有审美、有选品能力、有故事的小众香水店”。

建议首页模块：

### 3.1 顶部公告栏

用于放置重要购买信息：

- 满额包邮
- 新客试香套装
- 线下试香预约
- 海外配送说明
- 节日礼盒活动

示例文案：

> 新客试香套装上线，可按香调、场景或买手推荐选择。

### 3.2 主视觉 Hero

主视觉应使用真实香水瓶、品牌视觉、门店陈列或高质感香氛场景图。

内容建议：

- 一款当季主推香水
- 一个新引入品牌
- 一个主题香调，例如“茶香季”“雨天木质调”“夏日白花”

按钮建议：

- 探索新品
- 查看买手推荐
- 开始选香

### 3.3 新品上架

展示最新到货商品。

商品卡片建议包含：

- 品牌
- 香水名称
- 容量
- 价格
- 主香调
- 新品 / 限量 / 热卖标签

### 3.4 买手推荐

这是小众香水店最应该突出的模块。

可以按场景或气味风格推荐：

- 干净通勤
- 温柔茶香
- 冷感木质
- 雨天焚香
- 约会白花
- 秋冬琥珀
- 不甜美食调
- 中性香水

每个推荐可以配一句简短说明，让用户知道为什么推荐。

### 3.5 品牌精选

展示核心品牌，不建议一开始堆太多。

每个品牌卡片建议包含：

- 品牌名
- 国家 / 地区
- 风格关键词
- 入门推荐款

示例：

> Parfum Satori  
> 日本美学、花香、焚香、细腻留白

### 3.6 试香服务

小众香水单价高，用户通常需要先试香。

建议首页明确展示：

- 试香小样
- 买手搭配试香套装
- 新客 discovery set
- 按香调组合
- 按场景组合

这是降低购买门槛的重要模块。

### 3.7 香水文章

文章区用于建立专业感和 SEO。

文章方向：

- 品牌介绍
- 单品测评
- 香调科普
- 季节推荐
- 礼物指南
- 如何试香
- 如何理解前调、中调、后调

### 3.8 门店 / 客服 / 社媒入口

如果有线下店或工作室，应放在首页底部。

如果没有线下店，也可以放：

- 微信
- 小红书
- Instagram
- WhatsApp
- 邮箱
- 客服时间

## 4. 商品列表页

商品列表页要帮助用户快速缩小选择范围。

建议分类：

- 香水
- 空间香氛
- 香氛蜡烛
- 试香小样
- 礼盒
- 限量款
- 新品

建议筛选项：

- 品牌
- 价格
- 香调
- 容量
- 浓度
- 场景
- 性别中性
- 库存状态
- 新品 / 限量 / 热卖

香调筛选建议：

- 柑橘
- 花香
- 白花
- 茶香
- 木质
- 焚香
- 琥珀
- 麝香
- 皮革
- 绿意
- 水感
- 美食调
- 烟草
- 辛香

商品卡片建议显示：

- 产品图
- 品牌名
- 商品名
- 容量
- 价格
- 1-3 个香调标签
- 库存状态

## 5. 商品详情页

商品详情页要同时完成“种草”和“转化”。

建议结构：

### 5.1 商品基础信息

- 商品图片
- 品牌名
- 商品名
- 容量
- 浓度，例如 EDP、Extrait、Parfum
- 价格
- 库存状态
- 数量选择
- 加入购物车
- 收藏

### 5.2 香调结构

建议固定展示：

- 前调
- 中调
- 后调
- 调香师
- 发布年份
- 香调家族

### 5.3 气味描述

不要只写成分表，要有画面感。

可以包含：

- 第一印象
- 扩散后的变化
- 留香后的质感
- 适合什么季节
- 适合什么人
- 是否适合盲买

### 5.4 买手点评

这是区别普通电商和买手店的关键。

示例结构：

- 为什么选它
- 它和常见商业香有什么不同
- 谁会喜欢它
- 谁可能不适合

### 5.5 规格与配送

必须清楚写：

- 容量
- 产地
- 包装
- 是否原装正品
- 发货时间
- 配送方式
- 退换政策
- 海外配送说明

### 5.6 相关推荐

推荐逻辑：

- 同品牌
- 同香调
- 同场景
- 同价位
- 可搭配试香小样

## 6. 品牌页

品牌页是小众香水网站的重要内容资产。

每个品牌页建议包含：

- 品牌故事
- 国家 / 地区
- 创办人
- 调香师
- 品牌风格关键词
- 材料或工艺特点
- 买手推荐入门款
- 该品牌全部商品

品牌页的语气应像杂志介绍，而不是商品说明书。

选香指南可以做成普通页面，也可以后续升级成互动问卷。

建议分类：

### 7.1 按香调选

- 茶香
- 木质
- 白花
- 柑橘
- 麝香
- 焚香
- 琥珀
- 美食调

### 7.2 按场景选

- 日常通勤

- 安静独处
- 秋冬氛围
- 夏天清爽

### 7.3 按个性选

- 冷感

## 8. 香水文章 / Journal

文章区的作用：

- 建立专业感
- 帮助用户理解小众香水
- 承接搜索流量
- 支持社媒内容二次分发

文章类型建议：

- 单品深度测评
- 品牌介绍
- 调香师介绍
- 香调科普
- 季节香水推荐
- 礼物指南
- 新品上架故事
- 买手清单

文章标题示例：

- 适合夏天的 7 款茶香香水
- 第一次买小众香水，应该从哪些香调开始
- 木质香不一定沉重：5 款干净木质调推荐
- 白花香水为什么有人觉得高级，有人觉得压迫
- 如何正确试香，避免买错

## 9. 关于我们

关于我们页面要讲清楚“为什么用户应该相信我们”。

建议内容：

- 我们是谁
- 为什么做小众香水买手店
- 我们如何选择品牌
- 我们如何试香和推荐
- 是否有线下试香
- 正品渠道说明
- 客服方式
- 社媒入口

语气建议真诚、具体，不要写成空泛品牌宣言。

## 10. 视觉设计方向

建议整体风格：

- 安静
- 高级
- 有编辑感
- 细腻
- 不过度商业化

视觉原则：

- 大面积留白
- 高质量产品摄影
- 字体清晰，排版克制
- 商品图片要真实、明亮、可看清瓶身
- 色彩不要太花，避免廉价感
- 首页可以更有氛围，商品页要更清楚、实用

推荐色彩方向：

- 暖白
- 石灰灰
- 深墨绿
- 烟灰黑
- 柔和金色点缀
- 少量酒红或茶褐作为强调色

需要避免：

- 过度网红风
- 太多渐变
- 太多装饰元素
- 商品图太暗
- 文案过度玄学，看不出具体气味

## 13. 分阶段制作计划

### 第一阶段：基础电商版

目标：先能上线销售。

页面：

- 首页
- 商品列表
- 商品详情
- 品牌列表
- 关于我们
- 购物车
- 结账
- 配送与退换政策

重点：

- 购买流程清楚
- 商品信息完整
- 页面视觉统一
- 移动端体验正常

### 第二阶段：内容型买手店

目标：建立专业感和用户信任。

新增：

- 品牌故事页
- 香水文章
- 买手推荐专题
- 试香套装页
- 按香调 / 场景选香

重点：

- 让用户知道我们会选品
- 用内容带动购买
- 提升复购和收藏

### 第三阶段：选香体验升级

目标：让用户更容易找到适合自己的香水。

新增：

- 选香问卷
- 个性化推荐
- 商品收藏
- 到货通知
- 会员系统
- 预约试香

重点：

- 降低选择困难
- 提升转化率
- 增强用户粘性

## 14. 推荐的第一版页面顺序

如果预算或时间有限，建议先做这些：

1. 首页
2. 商品列表页
3. 商品详情页
4. 品牌页
5. 试香套装页
6. 关于我们
7. 配送与退换政策

文章和选香问卷可以第二阶段再做。

## 15. 网站核心卖点总结

这个网站不应该只是“卖香水”，而应该传达：

- 我们帮你从大量小众品牌里筛选真正值得闻的作品
- 我们提供比普通电商更细的气味描述和买手建议
- 你可以先通过小样和试香套装降低试错成本
- 每个品牌和每款香水都有故事、工艺和审美
- 香水不按性别销售，而是按气味、场景和个人感受推荐

最终目标是让用户感觉：

> 这里不是普通香水店，而是一个可以慢慢发现气味、理解品牌、找到自己气味风格的地方。
