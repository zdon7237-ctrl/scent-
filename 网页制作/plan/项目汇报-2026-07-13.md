## 四、当前问题与风险

| 优先级 | 项目 | 影响 | 处理建议 |
| --- | --- | --- | --- |
| P0 | Blob 运行时写凭据缺失 | 后台不能上传或删除商品图片；其他后台功能正常 | 在 Vercel Blob 中补齐 Function 可用的写凭据，再验证上传与删除 |
| P0 | 未完成 Production 订单全流程演练 | 人工核款、发货、积分和退款虽然有测试，但未在真实域名串联演练 | 使用内部账号和小额测试订单走完下单到退款 |
| P1 | 长期备份不足 | Neon 免费版只有 6 小时历史，临时迁移前分支会自动删除 | 建立周期性导出或升级备份能力，并演练只读恢复 |
| P1 | Production/Preview 共享 Blob、Upstash、Resend | Preview 测试可能消耗正式额度或污染资源 | 低量期谨慎操作；后续分别创建 Preview 资源 |
| P1 | 两个 Owner 的密码管理 | 共用或重复密码会扩大泄露影响 | 两个 Owner 分别修改为独立密码并撤销其他 Session |
| P2 | 试香商品缺失 | 试香页显示整理中，不能销售 3 个套装 | 准备销售时在后台补录并验证库存、价格和结账 |
| P2 | Hobby 套餐与账单资料 | 免费额度可能够低量试营，但条款、告警和支持能力有限 | 观察用量并处理账单地址；正式放量前评估 Pro |

## 五、接下来建议

1. 先修复商品图片上传凭据。
2. 用内部顾客账号完成一笔“下单 -> 人工核款 -> 发货 -> 确认收货 -> 积分 -> 退款”演练。
3. 两个 Owner 分别修改独立密码，并检查 Session。
4. 建立每周数据库备份记录和每月恢复核对。
5. 试香套装准备好后再录入，不阻塞普通香水试营业。
6. 客户量增加后再拆分 Preview 资源并评估 Vercel 商业套餐。
