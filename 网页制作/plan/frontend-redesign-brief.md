# 前端整体改版 Brief

更新日期：2026-05-06

## 1. Feature Summary

本 brief 对应 `frontend-goal-plan.md` 的 Goal 2，并承接 `frontend-critique-report.md` 的审计结论。改版目标是把当前可运行的多页面电商站，打磨成更像小众香水买手店的前端体验，同时保持购买、会员、积分流程清晰稳定。

默认 register 是 `brand`；但商品列表、商品详情、购物车、登录、账户、会员和积分页面按 `product` 原则处理。

## 2. Primary User Action

用户进入网站后，应能快速判断自己该走哪条路径：

```text
我想直接买 -> 香水列表
我不确定买什么 -> 选香指南 / 试香套装
我想看审美和专业度 -> 品牌 / Journal
我已经有会员 -> 会员中心 / 积分商城
```

## 3. Design Direction

**Color strategy:** Restrained。沿用暖纸色、深苔绿、旧金色、亚麻线色和卡片白；不扩大金色和深绿色的装饰面积。

**Theme scene:** 国内用户在手机上浏览一家安静的小众香水买手店，可能是晚上通勤后、周末选礼物前、或第一次准备买正装前，状态是好奇但需要被专业引导。

**Anchor references:** 精品香水买手店货架、编辑型香水专栏、安静的试香工作室。

## 4. Scope

- **Fidelity:** production-ready frontend polish。
- **Breadth:** 全站核心前端流程，重点是首页、购买链路、内容信任页、会员积分页。
- **Interactivity:** 保留现有 JS 架构，不引入新框架。
- **Time intent:** 以当前静态站为基础做稳定改版，不重写后端和业务规则。

## 5. Layout Strategy

### 首页

首页负责建立气质和分流，不承担完整商品列表职责。首屏要避免指标模板，改为气味判断和行动入口。页面节奏以“主视觉 -> 选香入口 -> 编辑推荐 -> 试香 -> 品牌/文章”为主。

### 商品列表

列表页按 product 规则处理。筛选栏保持清楚，但移动端要减少压迫感。商品卡片增加场景和买手判断，让新手不用进入详情也能初步判断。

### 商品详情

购买区前置价格、容量、浓度、库存、加入购物车；同时紧贴 CTA 放置适合场景、买手提醒和试香入口。详情面板继续承载香调结构、买手点评和服务政策。

### 内容页面

品牌和 Journal 不再只是 grid。每个入口页都要说明“如何用这个页面选香”，并自然导向品牌商品、文章商品或试香。

### 会员与积分

会员、订单、积分、积分商城保持 product 风格：清楚、稳定、低装饰。重点是状态、积分余额、下一步和错误恢复。

## 6. Key States

- **Default:** 页面内容完整，主行动清楚。
- **Empty:** 购物车、订单、积分流水、兑换记录、积分商城无数据时必须告诉用户下一步。
- **Loading:** 会员、订单、积分等异步页面显示“正在读取”并保持稳定空间。
- **Error:** 接口失败时显示可理解错误，不只依赖 toast。
- **Success:** 加入购物车、登录、保存资料、兑换成功必须有明确反馈。
- **Disabled:** 库存不足、积分不足、提交中状态要禁用按钮并说明原因。
- **Mobile:** 375px 宽度下不出现文字溢出、按钮重叠和表格不可读。

## 7. Interaction Model

- 导航：桌面顶部导航，移动端展开导航；搜索提交进入 `shop.html?q=...`。
- 筛选：列表页筛选即时刷新结果数，空结果提示清除筛选或先试香。
- 商品卡：查看详情、收藏、加入购物车三种意图清楚区分。
- 商品详情：主 CTA 加入购物车，次 CTA 指向试香或服务。
- 购物车：数量调整即时更新，空状态引导探索香水和试香。
- 会员/积分：表单提交中禁用按钮，错误可恢复。

## 8. Content Requirements

文案必须像买手建议，而不是广告语。

需要补充的文案类型：

- 首页三条用户路径：直接买、先试香、看买手内容。
- 商品卡：适合场景、香调家族、低风险标签。
- 商品详情：盲买提醒、试香建议、适合人群。
- 试香页：为什么先试、怎么选套装、怎么抵达正装购买。
- 品牌页：品牌选择逻辑和入门路线。
- Journal：文章如何帮助购买，不做孤立内容。
- 会员页：积分、订单、兑换状态的下一步说明。

## 9. Implementation Order

1. 首页与全局状态基础。
2. 商品列表、商品卡、商品详情、购物车。
3. 试香页、品牌、Journal、关于我们、服务。
4. 登录、账户、会员、订单、积分、积分商城。
5. 移动端、focus、状态、构建验收。
