# 小众香水买手店多页面网站设计计划

## 1. 当前问题

目前网页已经覆盖了原计划里的大部分内容，但页面形态更像一个“完整策划案展示页”：所有模块都堆在首页，用户需要一直向下滚动才能看到商品、品牌、试香、文章、关于我们和服务信息。

这会带来几个问题：

- 首页信息过重，缺少高级买手店应有的留白和节奏
- 用户无法形成清晰的浏览路径
- 商品购买、品牌了解、试香服务、文章阅读混在一起
- 页面看起来像 demo，而不是正式电商网站
- 后续添加更多商品或文章时，首页会越来越臃肿

下一版应改成“多页面精品电商结构”：首页负责建立气质和分流，其他页面负责具体内容与购买。

## 2. 新版网站定位

新版网站应定位为：

> 一个有编辑感、有选品判断、支持试香和购买的小众香水买手店网站。

它不应该像普通货架电商，也不应该像品牌宣传页。它应该介于两者之间：

- 有电商购买效率
- 有买手店的审美和内容感
- 有清楚的品牌、香调、场景分类
- 有试香服务降低购买门槛
- 有文章和选香指南建立专业感

## 3. 核心设计原则

### 3.1 首页只做入口

首页不再展示完整内容。首页只负责：

- 让用户知道这是什么店
- 展示当季主推内容
- 引导用户进入商品、品牌、试香、选香指南或文章
- 建立高级、安静、有审美的第一印象

首页不应该承担：

- 完整商品列表
- 完整品牌故事
- 完整文章列表
- 完整关于我们
- 完整配送退换政策

### 3.2 内容分层

把不同目的的内容拆到不同页面：

- 想买香水的人去商品列表
- 想了解品牌的人去品牌页
- 不确定买什么的人去选香指南
- 怕盲买的人去试香套装
- 想看内容的人去 Journal
- 想了解店铺可信度的人去关于我们

### 3.3 首页要有留白和节奏

首页应该像精品店橱窗，而不是仓库清单。

建议首页只保留 6-8 个主要区块，每个区块有明确跳转按钮。

### 3.4 商品页要清楚实用

商品详情页可以有气味故事，但购买信息必须清楚：

- 价格
- 容量
- 库存
- 浓度
- 加入购物车
- 香调结构
- 配送退换
- 买手点评

### 3.5 内容要服务购买

文章、品牌故事和选香指南不是单独存在的内容页，它们应该能导向商品：

- 文章推荐相关香水
- 品牌页展示该品牌商品
- 选香结果跳转到商品详情
- 试香套装可以抵扣正装

## 7. 首页设计

首页目标：

> 用最少信息建立店铺气质，并把用户分流到正确页面。

### 7.1 首页结构

建议首页保留以下模块：

1. 顶部公告栏
2. 导航栏
3. Hero 主视觉
4. 当季主题推荐
5. 新品精选
6. 买手推荐入口
7. 品牌精选
8. 试香套装入口
9. Journal 最新文章
10. 页脚

### 7.2 Hero 主视觉

Hero 是首页最重要的视觉区域。

建议：

- 使用一张高质量香水氛围图
- 大面积留白
- 文案不超过 2 行主标题 + 2 行说明
- 保留 2 个主要按钮

示例结构：

```text
H1：从独立香水里，找到属于你的气味风格。
说明：我们以买手视角筛选独立品牌、调香师作品和少量限量香水。
按钮 1：探索香水
按钮 2：开始选香
```

Hero 不要放太多商品卡片，也不要放复杂筛选器。

### 7.3 当季主题推荐

用 3 个主题卡片引导用户：

- 茶香季
- 雨天木质
- 干净通勤

每个卡片点击后跳转到商品列表，并带对应筛选条件。

示例：

```text
index.html#tea-edit → shop.html?note=tea
index.html#office-edit → shop.html?scene=daily
index.html#wood-edit → shop.html?note=wood
```

### 7.4 新品精选

首页只展示 4-6 款新品。

商品卡片信息：

- 商品图
- 品牌
- 商品名
- 价格
- 1-2 个香调标签

点击商品卡进入 `product.html?id=xxx`。

不要在首页展开完整商品详情。

### 7.5 买手推荐入口

用编辑式入口代替完整列表：

- 干净通勤
- 温柔茶香
- 冷感木质
- 雨天焚香
- 不甜美食调
- 礼物推荐

每个入口跳转到商品列表筛选结果。

### 7.6 品牌精选

首页只展示 4 个核心品牌。

每个品牌卡片包含：

- 品牌名
- 国家 / 地区
- 风格关键词
- 入门推荐

点击进入品牌详情页。

### 7.7 试香套装入口

这是首页必须强调的转化入口。

建议做成一个横向大模块：

```text
不确定买哪一支？先从 6 支试香开始。
新客发现套装 / 茶香套装 / 木质套装
按钮：查看试香套装
```

### 7.8 Journal 最新文章

首页只展示 3 篇文章：

- 选香指南类
- 季节推荐类
- 品牌介绍类

点击进入文章详情。

- 库存

### 9.1 页面结构

```text
面包屑

```

### 9.2 商品主区域

左侧：

- 商品大图
- 缩略图
- 包装图
- 细节图

右侧：

- 品牌名
- 商品名
- 容量
- 浓度
- 价格
- 库存
- 数量选择
- 加入购物车
- 收藏

### 9.3 香调结构

固定展示：

- 前调
- 中调
- 后调
- 香调家族
- 调香师
- 发布年份

### 9.4 气味描述

文案不要过度玄学，要具体：

- 第一印象是什么

- 后调留下什么质感
- 扩散强不强
- 留香时间大概如何
- 是否适合盲买

### 9.5 买手点评

建议固定结构：

```text
为什么选它
谁会喜欢
谁不一定适合
和常见商业香的区别
```

### 9.6 规格与服务

必须清楚：

- 容量
- 产地
- 包装
- 发货时间
- 配送方式
- 退换政策
- 正品渠道说明

### 9.7 相关推荐

推荐逻辑：

- 同品牌
- 同香调
- 同场景
- 可搭配试香套装

## 11. 试香套装页设计

文件：`samples.html`

目标：

> 降低小众香水盲买门槛。

### 11.1 页面结构

```text
页面 Hero
为什么先试香
套装列表
如何试香
试香后如何买正装
FAQ
```

### 11.2 套装类型

建议第一版有：

- 新客发现套装
- 茶香套装
- 木质套装
- 通勤套装
- 礼物试香套装

每个套装展示：

- 包含几支
- 每支容量
- 覆盖哪些香调
- 适合谁
- 价格
- 是否可抵扣正装

### 11.3 试香说明

必须告诉用户：

- 不要一次试太多
- 先闻试香纸，再上皮肤
- 每支至少观察 3-6 小时
- 不要只以前调判断
- 记录喜欢和不喜欢的点

## 12. 选香指南页设计

文件：`guide.html`

目标：

> 帮助不确定需求的用户找到方向。

### 12.1 页面结构

```text

按香调选
按场景选
按个性选
选香问卷

```

### 12.2 按香调选

入口：

- 茶香
- 木质
- 花香
- 柑橘
- 焚香
- 麝香
- 琥珀
- 美食调

每个入口跳转到商品列表筛选结果。

### 12.3 按场景选

入口：

- 日常通勤
- 第一次约会
- 安静独处
- 送礼
- 秋冬
- 夏天
- 睡前

### 12.4 选香问卷

第一版问卷控制在 5-7 题。

问题方向：

- 喜欢干净还是温暖
- 是否接受甜感
- 使用场景
- 希望扩散强还是贴肤
- 喜欢自然感还是艺术感
- 是否用于送礼

结果：

- 推荐 3-5 款香水
- 推荐 1 个试香套装
- 每个推荐给一句理由

## 16. 购物车设计

购物车可以有两种方案：

### 16.1 抽屉式购物车

适合第一版。

优点：

- 用户不用离开当前页面
- 加入购物车反馈明显
- 开发简单

### 16.2 独立购物车页

适合后续正式电商。

结构：

```text

```

第一版建议继续用抽屉式购物车，后续再加 `cart.html`。

## 17. 视觉设计方向

### 17.1 整体气质

关键词：

- 安静
- 高级
- 有编辑感
- 有留白
- 不网红
- 不廉价
- 不过度装饰

### 17.2 色彩

推荐主色：

- 暖白
- 石灰灰
- 烟灰黑
- 深墨绿
- 柔和金色
- 少量酒红

避免：

- 大面积纯黑
- 大面积紫色渐变
- 过多奶茶色
- 过度网红粉
- 颜色太满

### 17.3 字体

建议：

- 中文正文使用清晰无衬线
- 英文小标题可以使用大写字母
- Hero 标题可以使用衬线字体
- 商品信息必须易读

字号建议：

- Hero H1：56-88px desktop，38-48px mobile
- 页面 H1：42-60px desktop，32-40px mobile
- 区块 H2：32-48px
- 商品名：18-22px
- 正文：15-17px

### 17.4 图片

正式网站不建议继续用外链图片。

应准备本地图片：

```text
assets/images/hero.jpg
assets/images/product-xxx.jpg
assets/images/brand-xxx.jpg
assets/images/article-xxx.jpg
assets/images/sample-set.jpg
```

图片要求：

- 商品图清楚看到瓶身
- 背景干净
- 色温统一
- 不要过暗
- 不要过度氛围化到看不清商品

### 17.5 卡片和布局

卡片不要太圆，建议 6-8px radius。

页面不要到处都是卡片，卡片只用于：

- 商品
- 品牌
- 文章
- 试香套装

页面大区块应以留白、图片和排版区分，不要每个区块都做成浮动卡片。

## 18. 移动端设计

移动端是重点，因为香水买手店用户很可能从小红书、Instagram 或微信进入。

### 18.1 导航

- 顶部只保留 Logo、菜单、购物车
- 搜索放入菜单或独立搜索页
- 菜单展开后显示主要导航

### 18.2 首页

- Hero 图片不能过高导致用户看不到入口
- 首页每个模块最多显示 2-4 个内容
- CTA 按钮要明显

### 18.3 商品列表

- 筛选按钮固定在顶部或底部
- 点击后打开筛选抽屉
- 商品卡片 1 列或 2 列
- 价格和库存必须可见

### 18.4 商品详情

手机端建议底部固定购买栏：

```text
价格 / 加入购物车
```

这样用户看完香调和点评后，不需要滚回顶部。

## 19. 数据与内容组织

建议把商品数据从 `script.js` 拆出来：

```text
data.js
```

数据结构：

```js
{
  id: "vespree",
  brand: "Maison Bienaime",
  name: "Vesprée 晚霞之约",
  price: 980,
  volume: "75ml",
  concentration: "EDP",
  category: "fragrance",
  notes: ["木质", "花香", "辛香"],
  scenes: ["daily", "date", "gift"],
  image: "assets/images/product-vespree.jpg"
}
```

后续所有页面都从同一份数据读取，避免重复维护。

## 20. 第一版重构范围

建议第一版先做这些页面：

1. `index.html`
2. `shop.html`
3. `product.html`
4. `brands.html`
5. `samples.html`
6. `guide.html`
7. `journal.html`
8. `about.html`
9. `service.html`

先不做：

- 完整会员系统
- 真正支付
- 后台管理
- 真实库存同步
- 多语言

但页面上可以预留入口。

## 21. 开发执行顺序

### 第一步：拆数据

把商品、品牌、文章、试香套装数据统一放到 `data.js`。

### 第二步：重做首页

把首页改成精品入口页，只保留精选内容和跳转按钮。

### 第三步：做商品列表页

实现筛选、搜索、排序和商品卡片跳转。

### 第四步：做商品详情页

用 URL 参数读取商品：

```text
product.html?id=vespree
```

### 第五步：做品牌、试香、选香、文章页面

这些页面可以先做静态内容，再逐步接数据。

### 第六步：统一导航、页脚和购物车

所有页面保持统一体验。

## 22. 成功标准

新版完成后，应达到以下效果：

- 首页不再像长文档，而像正式买手店首页
- 用户能通过导航跳转到不同页面
- 商品详情是独立页面，不再藏在首页弹窗里
- 品牌、试香、选香、文章都有独立入口
- 购买路径更清晰
- 移动端可用
- 后续商品增加时不需要继续加长首页

## 23. 最终目标

新版网站应该让用户感觉：

> 这是一家有审美、有判断、有内容的小众香水买手店。我可以慢慢探索，也可以快速找到适合自己的香水。

首页负责建立气质，商品页负责购买，品牌页负责信任，试香页负责降低门槛，文章和选香指南负责长期种草。
